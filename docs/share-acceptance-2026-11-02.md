## 対象と維持する契約

- 正式名：ゴリラ豪雨。既存 canonical は https://chameleonjp-lab.github.io/goriragouu/ 。
- 既存ホーム・結果の X intent を維持し、共有文に `#ゴリラ豪雨 #ゲーム制作` を追加する。独立したコピー操作は元からなく、X を開けない場合のコピー／prompt フォールバックは維持する。
- 採点、60 秒の基本時間、ボーナス、参加者 ID、保存済み結果、匿名開始、音声、ゲームの描画・難易度は変更しない。

## 検証の分離

- 従来のブラウザ検査（結果 fixture、通信失敗から同一提出の再送、保存失敗、音量）を残す。
- 別 mobile context でホーム 15 言語、代表 ja/en/de の縦横・短い高さ、結果 15 言語を検査する。X 自身と祖先の可視性、中央 hit、44px、文字切れ、黒白、押下時の色、実 intent の文言・URL を確認する。
- 対象へ scrollIntoView して検査するため、初期 viewport に常時見えることや全画面の全内容が切れないことの証明ではない。
- 名前なし・音オフで通常の開始ボタンから開始し、実時間で自然終了する。採点値や終了関数を設定しない。結果の言語変更で経過・取得数・結果状態が変わらないことを検査する。
- 同一 origin の静的 GET/HEAD だけ許可し、redirect、外部通信、WebSocket、Service Worker を拒否する。ランキングは明示的なローカル mock のみで、実スコア API に送信しない。未知の mock RPC も失敗とする。
- 画像取得は本物の renderer 呼出を 1:1 委譲した直後の canvas 読取。強制描画、強制出現、時刻・乱数・位置の変更は行わない。

## 途中の不成立と是正

- 最初の CI `41419129008` / `bd624d25ea22838b05e620f645c9eba4c9f9ef8a` は unit 109 件成功後、Chromium が実開始で fullscreen に入り、素材取得後の viewport resize をブラウザに拒否された。結果受入と WebKit はこの実行では未完了。
- テスト側で素材取得後に標準 `exitFullscreen()` と解除待ちを行ってから viewport を戻す。製品 fullscreen 機能・ゲーム時間は変更しない。この protocol failure を製品 CSS の不具合とは扱わない。
- 開始直後の実画面は島・プレイヤー・バナナを確認できたがゴリラが不在のため、紹介画像の最終素材としては自然出現した実個体を含むフレームを優先する。初回画像は保全する。

- 2 回目の CI `41420947933` / `3924fa389e5d698d08441e7b69d8f22277fab17a` は resize 例外解消後、自然結果待ちが 120 秒で未達となった。blur/visibility で停止する正規機能との関係は、その実行に状態ログがなく未確定。
- 3 回目の CI `41422467616` / `3ece11357fe3405dddd14fd701806ed35b6c7350` は自然ゴリラ素材の 25 秒観測で未取得となり、後続結果受入へ未到達。素材取得をゲーム成功と同一視せず、次の検査では未取得の状態と画面を保存して既存結果受入を独立継続する。
- display 操作直後に実際の paused 状態と正規再開ボタンの可視を確認できた場合のみ、ボタンを通常 click 最大 1 回し、通常 countdown 後の playing 復帰を確認する。直接状態変更や無条件再開はしない。
