# ゴリラ豪雨

空から降り注ぐ「ゴリラ豪雨」を避けながら、球体の島で60秒間生き延びる3Dブラウザゲームです。PCとスマホの両方で遊べます。

## 遊び方

- PC：ゲーム画面を押したまま、逃げたい方向へマウスを動かします。矢印キーとWASDも使えます。
- スマホ：画面の中央寄りを押したまま、逃げたい方向へスワイプします。指を離すと止まります。
- ゴリラに触れるとゲームオーバーです。
- 足元まで見えている石に触れている間は移動速度が75%に下がります。複数の石に触れても重ねて減速しません。
- 木は半透明の壁です。プレイヤーもゴリラも通り抜けず、斜めに当たると樹冠の外周に沿って回り込みます。
- バナナを取ると2秒間加速します。加速中に続けて取ると、加速の残り時間へ2秒を足します。
- バナナ10本ごとに残り時間が5秒増えます。
- 生存30秒で豪雨が2地点、50秒で3地点に増えます。
- 豪雨の落下地点を示す円はありません。雲、雨、降下中のゴリラが同時に突然現れます。
- 同じ向きへ惑星の外周の4分の1（約47.1）走り続けると、通常の豪雨とは別に前方へ1地点追加されます。22.5度を超えて曲がるか、0.45秒以上止まると直進距離は数え直しになります。

PCは1地点につきゴリラ7体の「PC多群」、スマホは5体の「SP標準」です。端末でゲーム条件が違うため、結果にもモード名を表示します。通常豪雨と直進対策の豪雨は、豪雨の表示枠、ゴリラの追跡枠、乱数を分けているため、追加豪雨が通常の発生回数を減らすことはありません。

## 技術

- Three.js 0.185.1（バージョン固定のES Module）
- HTML / CSS / JavaScriptだけで動く静的サイト
- 外部画像・3Dモデル・音声素材なし
- ゴリラ、バナナ、木、岩は同じ形をまとめて描画
- 木と岩は描画時の球面位置と大きさを保存し、見た目と同じ配置で当たり判定
- 降下中のゴリラは、胴・顔・長い腕・脚を分けた8部品の共通造形
- 雨と敵はあらかじめ表示枠を用意して使い回す
- スマホは描画倍率と影を抑え、PCは雨量とゴリラ数を増やす
- 端末の速度が足りない場合は、木と岩の数や判定を変えず、描画解像度と装飾だけを下げる

Three.jsは次の固定URLから読み込みます。

```text
https://cdn.jsdelivr.net/npm/three@0.185.1/build/three.module.min.js
```

## ローカル確認

ES Moduleを使うため、`index.html`をファイルとして直接開かず、静的サーバーで配信してください。

```bash
python3 -m http.server 4173
```

その後、`http://localhost:4173/` を開きます。

自動テストはNode.js 20以上で実行できます。追加パッケージは不要です。

```bash
npm test
```

## 再現確認用URL

次のURLパラメーターで端末条件、軽量描画、乱数を固定できます。

```text
?device=sp&quality=low&seed=1234
?device=pc&seed=1234
```

`device=sp`をiPhone 17 Proで使っても、iPhone SE級の処理性能そのものを再現するわけではありません。小さい画面の配置確認と、軽量設定の動作確認に使います。

## ブラウザ操作について

ゲーム中はページのスクロール、長押し、ダブルタップ拡大、通常のピンチ操作を抑えます。ただし、iPhoneやAndroidの画面端から始まるOSのホーム操作・通知表示・戻る操作は、通常のWebページから完全には止められません。操作は画面端ではなく、中央寄りから始めてください。

## 公開

`main`へ反映すると、GitHub Pages用のワークフローが静的サイトを公開します。リポジトリ側でGitHub PagesのSourceを「GitHub Actions」に設定してください。
